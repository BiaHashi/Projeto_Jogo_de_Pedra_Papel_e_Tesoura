# Jogo de Pedra, Papel e Tesoura 

Jogo de pedra, papel e tesoura feito em aula de BootCamp por python contra o computador fazendo um front end com a bibloteca tkinter. 

---
## 📚 Aprendizados
- Modo de uso das bibliotecas Tkinter e random
- Interface do jogo
- Junção de códigos aprendidos em aula

## ⚙️ Funcionalidades
- Interface gráfica pela biblioteca Tkinter
- Jogador x Computador
- Sistema de rounds
- Botão de reset
- Sistema de placar entre vitória, empate e derrota
- Feedback a respeito do resultado do round

## 🛠️ Stack
- Python 3
- Biblioteca Tkinter
- Biblioteca Random

## 🚀 Deploy
1. Clone ou baixe este repositório.

```bash
git clone https://github.com/BiaHashi/Projeto_Jogo_de_Pedra_Papel_e_Tesoura
```

2. Abra os arquivos no Visual Studio Code com o Python instalado e execute pelo botão "Run Python File".
